# Every observed rejection message in the saved live experiments

Companion to [Deep dive 2](../DEEP_DIVE_2.md). Generated by [the census script](build-feedback-census.py). Scope: all saved live-model attempt feedback under `runs/`, including the two reported studies and both smaller live pilots. Offline replay/integration attempts are counted separately in the [scope record](evidence/deep-dive-2-census/scope.json); they did not send feedback to a live model.

The census contains **1506 attempts, 280 unaccepted attempts, 258 with a saved next request, and 22 without one**. One delivered feedback string was clipped mid-JSON. There are **69 distinct nonempty message strings**, of which **63 occur in full in at least one saved next prompt**.

Deduplication is by exact message text, across top-level and nested `message`/`log` fields. Repeated identical strings appear once. Different numeric values, locations, traceback lines, or provider request IDs remain separate exact variants. The family overview groups these variants without hiding any of them. The generic wrapper “A public fixture failed.” is also included once. An empty generator stderr cannot supply a nonempty message: the generator timeout is represented explicitly in the family table and its full case record.

“Sent” means present in a saved API request, not evidence that the model understood or acted on it. A final-attempt failure is still included even when no next request exists. These are observed rejections; a timeout, API failure, or unproved range is not automatically a counterexample to program correctness.
